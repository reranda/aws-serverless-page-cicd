A reviewed cloud release.

I'm Eranda Welgama. This independent lab demonstrates how a change in Git becomes a versioned AWS Lambda release, delivered over HTTPS through Amazon API Gateway.

From commit to deployment

  1. Change this HTML file and open a pull request.
  2. Run application tests and Terraform validation before merging.
  3. Generate a deployment plan using a temporary AWS identity.
  4. Review the saved plan and approve deployment.
  5. Verify the live page, health endpoint and release commit.

The page and handler travel together in a deterministic ZIP. Lambda reads the deployed file; it does not fetch GitHub during a request.
